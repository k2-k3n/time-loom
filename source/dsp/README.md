# Time Loom DSP

留住最近弹过的吉他片段并循环，释放后逐渐衰减。

## 使用方法

1. 先在 Resona Box 上安装本音频包。
2. 安装并打开 Time Loom 0.2.2。
3. 在 App 界面使用上方和下方编码器控制音色与功能。

## 配套关系

- 音频包：`org.resona.demo.time-loom-dsp`，版本 0.1.2
- App：`org.resona.demo.time-loom`，版本 0.2.2

完整界面及双编码器的旋转、短按、长按说明见 Time Loom 的社区项目页面。

DRY 淡入后直接输出吉他干声，强拨弦也保留原始动态。
